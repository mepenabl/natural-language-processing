# Natural Language Processing Projects

## Overview

This repository contains a collection of Natural Language Processing (NLP) laboratories developed throughout the course.

The projects progressively explore the evolution of NLP techniques, starting from classical machine learning approaches and static embeddings, and advancing towards transformer architectures, Large Language Models (LLMs), semantic retrieval systems, and Retrieval-Augmented Generation (RAG).

The repository was built as a practical portfolio showcasing:
- NLP preprocessing pipelines
- Machine learning for text classification
- Word embeddings
- Transformer architectures
- Large Language Models
- Semantic retrieval
- Retrieval-Augmented Generation systems
