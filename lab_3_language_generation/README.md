# Lab 3 - Natural Language Generation

## Overview

This laboratory explored Natural Language Generation (NLG) techniques using transformer-based language models, specifically GPT-2.

The project focused on analysing token probabilities generated by a language model and applying those probabilities to detect typographical errors in sentences.

The implementation was developed using:
- HuggingFace Transformers
- PyTorch
- NLTK
- NumPy
- Pandas

---

## Objectives

The main goals of the laboratory were:

1. Understand token probability distributions in transformer models
2. Compute token-level log probabilities
3. Compute cumulative sentence probabilities
4. Detect typos using probability drops between tokens
5. Evaluate the impact of different detection thresholds
6. Perform qualitative error analysis
