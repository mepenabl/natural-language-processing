# Lab 2 - Static Word Embeddings

## Overview

This laboratory focused on understanding and applying static word embeddings using different Natural Language Processing libraries and techniques.

The project explored both:
- the use of pre-trained embeddings
- the training of custom word embeddings on domain-specific data

The lab was implemented using:
- Gensim
- NLTK
- SpaCy
- NumPy
- Scikit-learn

---

## Objectives

The main goals of the laboratory were:

1. Work with pre-trained word embeddings
2. Compute semantic similarities between words
3. Evaluate embeddings using intrinsic evaluation metrics
4. Apply NLP preprocessing techniques
5. Train custom Word2Vec embeddings
